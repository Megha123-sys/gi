# Megha's Portfolio Website

A modern, responsive personal portfolio website for Megha, a performance marketing professional based in Delhi, India.

## Features

### 🎨 Design
- Clean, modern design with soft shadows
- Pastel color palette with gradient accents
- Mobile-first responsive design
- Smooth animations and transitions
- Professional typography using Inter font

### 📱 Responsive Design
- Fully responsive across all devices
- Mobile-optimized navigation with hamburger menu
- Adaptive grid layouts
- Touch-friendly interface elements

### 🚀 Sections Included
1. **Hero Section** - Professional introduction with animated stats
2. **Services** - Performance Marketing, Brand Building, Meta & Google Ads, Digital Strategy
3. **Portfolio** - 4 sample campaigns with KPIs and results
4. **About Me** - Personal story of resilience, ambition, and growth
5. **Contact** - Functional contact form with validation
6. **Footer** - Social links and contact information

### ⚡ Interactive Features
- Smooth scrolling navigation
- Animated counters for statistics
- Hover effects on cards and buttons
- Form validation and submission feedback
- Mobile navigation toggle
- Parallax scrolling effects
- Intersection Observer animations

### 🛠️ Technical Implementation
- **HTML5** - Semantic markup with accessibility features
- **CSS3** - Modern CSS with Flexbox and Grid
- **Vanilla JavaScript** - No frameworks, optimized performance
- **Font Awesome Icons** - Professional iconography
- **Google Fonts** - Inter typography

## Customization

### Colors
The color scheme uses CSS custom properties and can be easily modified in the `styles.css` file:
- Primary: `#667eea` (Blue gradient start)
- Secondary: `#764ba2` (Purple gradient end)
- Background: `#fafafa` (Light gray)

### Content
- Update personal information in `index.html`
- Modify service descriptions and portfolio items
- Replace placeholder images with actual campaign visuals
- Update social media links in the footer

### Contact Form
The contact form currently shows a success message without actual email sending. To implement real email functionality:
1. Set up a backend service (e.g., Formspree, Netlify Forms)
2. Update the form action attribute
3. Modify the JavaScript submission handler
